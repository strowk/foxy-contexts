[Examples folder](https://github.com/strowk/foxy-contexts/tree/main/examples) contains examples of how to use [Foxy Contexts](https://foxy-contexts.str4.io/) library.

## Tools

This [example](https://github.com/strowk/foxy-contexts/tree/main/examples/list_k8s_contexts_tool/main.go) demonstrates how MCP tool could be defined using NewTool.

## Prompts

This [example](https://github.com/strowk/foxy-contexts/tree/main/examples/list_k8s_namespaces_prompt/main.go) demonstrates how MCP prompt could be defined using NewPrompt.

## Resources

This [example](https://github.com/strowk/foxy-contexts/tree/main/examples/hello_world_resource/main.go) demonstrates how basic static MCP resource could be defined using NewResource.

This [example](https://github.com/strowk/foxy-contexts/tree/main/examples/git_repository_resource/main.go) demonstrates how more complicated static MCP resource could be defined using NewResource.

This [example](https://github.com/strowk/foxy-contexts/tree/main/examples/k8s_contexts_resources/main.go) demonstrates how dynamic MCP resources could be defined using NewResourceProvider.

## Misc

This [example](https://github.com/strowk/foxy-contexts/tree/main/examples/streamable_http/main.go) demonstrates how MCP server could be started with streamable HTTP transport.
